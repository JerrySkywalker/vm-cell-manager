# Code of Conduct

This project follows the Contributor Covenant Code of Conduct, version 2.1.

Project interactions should remain technical, respectful, and focused on improving the software and documentation. Harassment, discrimination, threats, or sustained disruptive behavior are not acceptable.

For enforcement matters, contact the repository owner privately. Until the project grows a larger maintainer group, the repository owner is responsible for moderation and enforcement decisions.

The full Contributor Covenant text is available from the Contributor Covenant project at https://www.contributor-covenant.org/version/2/1/code_of_conduct/.
